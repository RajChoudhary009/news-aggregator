Personalized News Aggregator API

A RESTful API that fetches news articles based on each user's preferences. Built with Node.js, Express.js, bcrypt, JWT and NewsAPI.

Features
User signup and login with bcrypt password hashing
JWT-based authentication for protected routes
Get and update news preferences
Personalized news fetched from NewsAPI based on preferences
Input validation and proper error handling
In-memory caching of news responses (10 minute TTL) to save API quota and speed up responses
